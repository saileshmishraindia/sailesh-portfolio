VLSI For Freshers

A compact, hands-on introduction to VLSI fundamentals — digital logic, silicon basics, simple RTL with TL‑Verilog, and practical board-level debug workflows.

Course Overview

This mini-course is aimed at engineers new to VLSI and digital design. It covers:

  • Combinational logic (gates, adders, comparators)
  • Sequential elements (flip-flops, registers)
  • RTL flow with TL‑Verilog and Makerchip
  • FPGA prototyping and basic measurement (oscilloscope, logic analyzer)
  • Intro to PCB/board bring-up and soldering basics

Modules

  1. Intro & Tools — TL‑Verilog, Makerchip, simulation
  2. Logic Primitives & Combinational Circuits
  3. Sequential Basics — Flip-flops & Timing
  4. RTL Composition — Small datapaths
  5. FPGA Prototyping & Measurement
  6. Mini Project: 4-bit ALU

Hands-on TL‑Verilog Examples

1-bit Inverter

// TL‑Verilog: 1-bit inverter
\`default_nettype none

module inverter(input logic a, output logic y);
  always_comb y = ~a;
endmodule

1-bit D Flip-Flop

// TL‑Verilog: D flip-flop
module dff(input logic clk, input logic d, output logic q);
  always_ff @(posedge clk) q <= d;
endmodule

1-bit Full Adder (TL‑Verilog)

// TL‑Verilog: 1-bit full adder
module full_adder(input logic a, b, cin, output logic sum, cout);
  assign {cout, sum} = a + b + cin;
endmodule
