Project Overview

Why this supply matters

This design is a classic example of how discrete analog blocks work together to turn noisy AC input into a cleaner and more dependable DC output for small electronic loads.

The project uses a transformer-isolated input stage, a full-wave bridge rectifier, an LC filter, a zener regulator, and a 2N3904 emitter follower. The result is a regulated output around 6.1 V with better load handling than a zener-only arrangement.

From an engineering perspective, the emitter follower is the key refinement. It prevents the zener node from being directly burdened by the output load and lowers output impedance, which improves practical voltage stability.

The front end is equally important: after the transformer reduces the mains voltage, the bridge rectifier converts both halves of the AC cycle into pulsating DC, and the LC network suppresses the resulting 100 Hz ripple before the signal reaches the regulation stage. That means the zener diode is not asked to clean up a highly disturbed waveform on its own.

This also makes the design tradeoff easier to understand. The circuit gives up efficiency and some voltage headroom across the diode path and transistor junction, but in return it gains isolation, smoother DC behavior, clearer regulation, and a more robust output node for light-load analog or embedded applications.

Ripple management Full-wave rectification doubles the ripple frequency, and the LC stage is tuned to attenuate that component before regulation.
Reference integrity The zener establishes a stable base reference while the transistor carries the heavier current path to the load.
Practical outcome The output is cleaner, stiffer, and more usable than a bare rectifier or zener-only supply built at the same complexity level.
Objective Convert 230 V AC RMS into a usable regulated DC rail using standard discrete devices.
Core strategy Clean the waveform first, clamp a reference next, then buffer the final output for the load.
Best fit Educational analog labs, low-power sensor rails, embedded prototypes, and test setups.
System Architecture

Signal path from mains to regulated DC

Each block addresses a different problem in the conversion chain, from voltage reduction and rectification to ripple suppression and load-aware output regulation.

01

AC Input + Transformer

A 230 V AC source is stepped down using a modeled transformer with an effective turns ratio of approximately 20:1.

02

Full-Wave Rectifier

Four diodes form a bridge rectifier to convert the secondary AC waveform into pulsating DC.

03

LC Filtering

An inductor and capacitor combination attenuates ripple, producing a much smoother pre-regulation voltage.

04

Zener Regulation

A 6.8 V zener with a 60 ohm series resistor establishes a controlled reference node.

05

Emitter Follower Output

A 2N3904 transistor buffers the regulated node so the output can drive load current more effectively.

Step-by-step voltage chain

1. AC input source

The mains source is modeled as a sinusoid with 50 Hz frequency and a peak value of 339.41 V.

Vin(t) = 339.41 sin(2 pi x 50t) V, with Vrms ~ 339.41 / sqrt(2) ~ 240 V
2. Transformer step-down

The inductors are modeled with a turns ratio of about 20:1, reducing the primary peak voltage to the secondary side.

n = sqrt(L1 / L2) = sqrt(400 mH / 1 mH) = 20 Vsec,peak = 339.41 / 20 ~ 16.97 V
3. Bridge rectifier drop

Two diodes conduct in each half-cycle, so the bridge removes about 1.4 V from the secondary peak.

Vdc,peak = 16.97 - 2 x 0.7 ~ 15.57 V
4. Filtered pre-regulation voltage

With a 100 Hz ripple frequency after full-wave rectification and C1 = 246 uF, the capacitor ripple estimate is about 4.07 V at 100 mA.

Delta V ~ Iload / (f x C) = 0.1 / (100 x 246 x 10^-6) ~ 4.07 V Smoothed DC minimum ~ 15.57 - 4.07 / 2 ~ 13.5 V
5. LC cutoff behavior

The LC network is tuned well below the 100 Hz ripple component, so it strongly attenuates ripple before regulation.

fc ~ 1 / (2 pi sqrt(LC)) = 1 / (2 pi sqrt(1 mH x 246 uF)) ~ 10.1 Hz

Regulation, load, and power math

6. Zener regulation current

The zener is biased from the filtered rail through a 60 ohm resistor, establishing a 6.8 V reference node.

VR2 = 13.5 - 6.8 = 6.7 V IR2 = 6.7 / 60 ~ 111.7 mA Iz = IR2 - Iload, and should remain above about 5 mA
7. Emitter follower output

The 2N3904 output node follows the zener base voltage minus the base-emitter drop.

Vout ~ Vb - Vbe ~ 6.8 - 0.7 ~ 6.1 V
8. Output capacitor transient support

For a 50 mA load step lasting 1 ms, the 100 uF output capacitor limits the output droop to around half a volt.

Delta V = I x Delta t / C = 50 x 10^-3 x 1 x 10^-3 / 100 x 10^-6 = 0.5 V
9. Load current

Using a 104 ohm resistive load, the final current draw is just under 60 mA.

Iload = 6.1 / 104 ~ 58.7 mA
10. Power and efficiency

The output rail is stable but the topology is intentionally simple, so efficiency remains low in exchange for transparency and ease of study.

Pin ~ 12 W (repository design estimate) Pout = 6.1 x 0.0587 ~ 0.358 W eta ~ (0.358 / 12) x 100 ~ 2.98%

Interpretation

Ripple vs cutoff

The 100 Hz ripple sits well above the 10.1 Hz LC cutoff, which is why the filter substantially smooths the rectified waveform.

Why the buffer matters

The zener establishes the voltage reference, but the transistor supplies the load current, so the reference node stays less disturbed.

Main tradeoff

This architecture is electrically easy to understand and stable for light loads, but it sacrifices efficiency because it relies on linear drops and dissipation.

Performance View

What the design achieves in practice

The circuit is intentionally simple, so the tradeoff is clear: strong educational value and stable low-power output at the cost of linear-regulator efficiency.

Voltage regulation

The zener and transistor stages maintain an output near 6.1 V across reasonable load changes and input ripple variations.

Ripple reduction

The LC filter suppresses the 100 Hz ripple component from full-wave rectification before the voltage reaches the regulation stage.

Load capability

The emitter follower improves current delivery by isolating the zener node from direct load demand.

Transient smoothing

The output capacitor helps minimize output fluctuations during short load-step events.

Protection behavior

Diode drops and the series resistor help limit overcurrent stress and clamp the reference stage safely.

Efficiency tradeoff

The project estimates roughly 3 percent efficiency, which is expected for a simple linear approach and acceptable for learning-focused low-power use.

Applications

Where this architecture fits

This is a practical reference design for low-power analog and embedded environments where simplicity and transparency matter more than high conversion efficiency.

Embedded prototypes

Useful for powering small controller boards or sensor interfaces that need a simple regulated DC source.

Electronics laboratories

Clear stage-by-stage behavior makes it ideal for demonstrations of rectification, filtering, and regulation.

Reference generation

The zener stage illustrates how a basic voltage reference can be stabilized before being buffered for output.

Measurement setups

Suitable for low-power auxiliary rails in bench experiments and proof-of-concept circuits.

Learning analog design

Shows the practical value of combining passive filtering with active buffering in a compact topology.

Discrete power studies

Good foundation for comparing classical linear supplies with later switch-mode alternatives.
