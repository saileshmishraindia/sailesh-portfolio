Public credential status / service not connected

Trust requires an authoritative record.

A certificate design or a correctly formatted ID is not proof of authenticity.

This interface is prepared for future registry integration. It cannot verify any certificate today.

Registry connection: unavailable

Certificate ID lookup

GitHub Pages hosts static files. No authoritative certificate backend or controlled verification dataset is connected. No certificate records or student personal details are stored in this frontend.

Provisional input format: 6–64 letters, numbers or hyphens, beginning with a letter or number. This checks format only. Do not enter a name, email address, Aadhaar number or other personal identifier.

Online verification is not connected

No certificate has been checked. Entering an ID will not establish whether it exists or is authentic. The current interface does not send IDs to a server, save them or place them in a URL.

No fabricated results. There is no hardcoded student array, demonstration certificate record or credential generated by this site. An unavailable service is not the same as an invalid certificate.
How a future service must work

Show status without exposing student records.

Before a result can be authoritative, an approved registry must control who can issue, correct, revoke and supersede credentials, preserve an audit trail and publish only proportionate public information.

Valid or not found

A valid result must come from an authorised registry, not a local ID-format test. A not-found result can only follow an actual registry lookup and should not expose unrelated records.

Revoked or superseded

A future result must distinguish a withdrawn credential from one replaced after correction. Private misconduct details and replacement-holder information should not be disclosed.

Unavailable

No connection, an unconfigured service or a lookup failure must never be reported as a successful verification or as evidence that the credential does not exist. Today, this is the only registry state available.

Privacy-first integration. A future lookup should return only the certificate ID, course title, issue date and current status where lawful. Do not expose student names, email, birth dates, marks or identity documents by default. Apply access control for administrative changes, rate limiting, abuse monitoring and a published correction route. Final policy and legal review are required before launch.
