SystemVerilog Code (User Editable)

Design
module SRAM #(
    parameter ADDR_WIDTH = 8,
    parameter DATA_WIDTH = 8,
    parameter DEPTH = 256
)(
    input clk,
    input reset,
    input [ADDR_WIDTH-1:0] addr,
    input [DATA_WIDTH-1:0] din,
    input we,
    input en,
    output reg [DATA_WIDTH-1:0] dout
);

reg [DATA_WIDTH-1:0] mem [0:DEPTH-1];
integer i;

always @(posedge clk or posedge reset) begin
    if (reset) begin
        dout <= {DATA_WIDTH{1'b0}};
        for (i = 0; i < DEPTH; i = i + 1)
            mem[i] <= {DATA_WIDTH{1'b0}};
    end else if (en) begin
        if (we)
            mem[addr] <= din;
        else
            dout <= mem[addr];
    end
end

endmodule
Testbench
module tb_SRAM;
    parameter ADDR_WIDTH = 8;
    parameter DATA_WIDTH = 8;
    parameter DEPTH = 256;

    reg clk, reset, we, en;
    reg [ADDR_WIDTH-1:0] addr;
    reg [DATA_WIDTH-1:0] din;
    wire [DATA_WIDTH-1:0] dout;

    SRAM #(ADDR_WIDTH, DATA_WIDTH, DEPTH) uut (
        .clk(clk), .reset(reset), .addr(addr), .din(din),
        .we(we), .en(en), .dout(dout)
    );
endmodule

Design Notes

  • The SRAM is parameterized by address width, data width, and memory depth for reuse across multiple small-memory scenarios.
  • When en is asserted and we is high, the input data is written into the selected address on the clock edge.
  • When en is asserted and we is low, data is read from the selected location and driven on dout.
  • The example interaction below performs a reset, writes 0x3C to address 0x0A, then reads it back to confirm functional behavior.
  • This is a visual teaching aid like the APB page, not a real HDL simulator, but it reflects the expected transaction flow of the reference design.

Timing Reference

Reset RESET = 1 clears the output register and returns the visible memory state to 0x00.
Write EN = 1, WE = 1 drives DIN into the selected address on the active clock edge.
Hold EN = 0 leaves the array unchanged and preserves the last committed contents.
Read EN = 1, WE = 0 returns the stored word from the selected address onto DOUT.
Demonstrated sequence: reset the SRAM, write 0x3C into address 0x0A, idle for one phase, then reassert EN with WE = 0 to read the same location back. This mirrors the control pattern shown in the example testbench and makes the relationship between waveform transitions and memory contents explicit.
