Op-Amp Based Function Generator

A precision analog function generator built around LT1498 op-amps to produce square, triangle, and sine waveforms from a multistage architecture. The design uses a comparator-like square-wave source, an integrator for linear ramps, and a shaping network to smooth the triangle into a sine-like output.

LT1498 Triangle / Sine / Square SPICE transient analysis ~1 kHz target range
Square-wave generation is set by RC timing and hysteresis around the op-amp switching stage.
Triangle waveform is generated by integration, making amplitude and slope directly tied to R and C values.
A resistor-diode shaping path improves sine-wave smoothness and lowers apparent distortion.
The repository also documents an LT1498 filter application and its gain plot for broader analog context.

3-Phase Op-Amp Oscillator Circuit

This project creates three sinusoidal outputs separated by 120 degrees using LT1493 op-amps, RC phase-shift sections, and diode-based amplitude stabilization. It is positioned as an analog tool for studying three-phase systems and feedback-driven sustained oscillation.

LT1493 120 degree phase separation RC feedback Diode limiter
Each amplifier stage contributes an additional phase shift through a 22 kohm and 100 nF network.
The closed-loop phase reaches 360 degrees when RC shift and inversion are combined, satisfying Barkhausen conditions.
The design documents an oscillation frequency around 121 Hz using the selected RC network.
The repository also includes a typical LT1493 precision AC-to-DC conversion application for broader op-amp usage context.

LC Colpitts Oscillator

An LC resonant oscillator using a capacitive divider and an active gain device to sustain sinusoidal oscillations. The project focuses on resonance, biasing, feedback magnitude, and how reactive elements determine frequency stability and oscillation startup.

Colpitts topology LC tank Common-emitter gain stage RF-oriented frequency setting
Two capacitors form the feedback divider while the inductor and effective capacitance set resonance.
The documented example uses C1 = C2 = 200 pF and L = 100 uH, yielding about 1.6 MHz oscillation.
Bias resistors, Rc, Re, and bypassing establish the transistor operating point for reliable startup.
The project highlights how nonlinear device behavior naturally limits amplitude and prevents runaway growth.

Dual-Stage Power Converter

A robust two-stage power architecture that combines a high-voltage LTC7138 buck front end with an LT8330 boost stage and enable-threshold logic. The design is documented as a bias voltage supply circuit intended to maintain a clean regulated rail even when the high-voltage input experiences surge or brownout conditions.

LTC7138 buck stage LT8330 boost stage EN / UVLO logic High-voltage input handling
The buck stage reduces an input near 140 V to about 15.7 V using a feedback divider and LC output smoothing.
An LT8330 enable network turns the boost stage on only after the intermediate rail rises above a safe threshold near 5.63 V.
The boost section regulates a final output around 10.47 V with additional filtering and a 100 ohm load model.
The project emphasizes transient tolerance, low ripple, and controlled startup behavior for sensitive analog and digital loads.

Quasi-Complementary Class-B Amplifier

A quasi-complementary push-pull Class-B amplifier designed for efficient moderate-power signal drive. The circuit uses an NPN and PNP output pair with diode-assisted biasing to reduce crossover distortion while retaining the efficiency benefits of Class-B operation.

Push-pull output stage 2N2222 / 2N2907 Diode biasing Audio load modeling
Q1 and Q2 form the upper and lower output devices, creating a symmetrical push-pull path for the signal swing.
A 1N914 diode establishes bias to reduce the dead zone around zero crossing and lower crossover distortion.
Large coupling capacitors pass low-frequency audio while blocking DC at the input and output interfaces.
The documented example uses an 8 ohm load to represent a speaker-class output target with near-unity voltage gain behavior.

Design Themes

Shared analog principles

The verified projects differ in purpose, but they revolve around the same core analog mechanisms: feedback, reactive timing, amplitude control, and operating-point discipline.

Feedback shaping

Oscillation and waveform conditioning are controlled through positive or regenerative feedback paths with carefully tuned loop conditions.

Reactive timing

RC and LC networks determine phase, frequency, and settling behavior, making component selection central to circuit performance.

Amplitude control

Diodes, bias choices, and device nonlinearity prevent uncontrolled gain and stabilize usable output waveforms.

Signal quality

Waveform purity, low distortion, and phase predictability appear repeatedly across the generator and oscillator projects.

Educational transparency

These circuits are good teaching vehicles because each block has a visible and explainable effect on the final output.

Simulation-first validation

The repositories emphasize plotted output behavior and theoretical calculations before any claim about practical usefulness.
